# security

#### 介绍

openGauss社区SIG Security小组负责接收和响应openGauss社区安全问题报告、提供社区安全指导，开展安全治理。同时负责openGauss社区License合规、开源第三方组件准入等合规审查工作。

security仓库用于SIG Security小组存放安全流程、安全指导、合规准则等相关的文档。
